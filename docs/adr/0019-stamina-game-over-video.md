# ADR-0019: スタミナ切れの後に動画を一度再生して結果選択へ戻す

- 日付: 2026-09-21
- 状態: `IN PROGRESS`（実装・公開検証中）
- 根拠: ユーザーの添付動画と「スタミナ切れでゲームオーバーになったらこの動画を一度だけ再生してゲーム終了でどうするか選択画面にまた戻る」、続くファイル・リポジトリ・リモート・Sites反映依頼。

## 文脈

現行の結果選択には「同じ設定でもう一度」「主人公・レベルを変更」がある。rankedのfinish送信は結果画面表示の前に待っていた。このまま動画を追加すると通信の遅れが動画の開始と結果選択の両方を遅らせる。

## 判断

[30章](../30_STAMINA_GAME_OVER_VIDEO_DESIGN.md)のとおり、Coreの`EXHAUSTED`から一度だけ8秒の動画を表示し、videoの`ended`で既存の結果選択を開く。`TIME_LIMIT`完走は従来どおり。動画の表示はclient UI状態として扱い、Coreとserver replayには追加しない。ranked finishは固定した結果と入力で並行送信し、送信未解決中の新ranked開始を止める。音声再生が禁止される端末には無音と明示的な再生操作を用意する。

## 理由と影響

終了理由の正本はCoreに残し、演出が競技結果を変えないようにする。ネットワークとメディアの失敗を互いに連鎖させず、必ず結果選択へ進める。実装はWeb frontendとversion付き動画だけで、D1 schema、ruleset、人物・ゾンビGLBを変更しない。
