# 33 選択画面のランキング上位3人

作成日: 2026-09-22（JST）。開始前の選択画面で、従来のゲームプレビュー領域へ当日のランキング上位3人を表示する。プレイを開始した後のゲーム画面と結果画面は維持する。丸印付きの参照画像はこの作業で確認できていないため、位置はプレビュー領域を基準とした。

## 表示

- 見出しは「ランキング」。対象の「今日・初級／中級／上級」と「上位3人」を添える。
- `GET /api/v1/leaderboards/daily?ruleset_id=...` のサーバー確定順を使い、先頭3件だけを順位・公開名・距離の表に表示する。距離は小数第2位までのm。完走記録には「30:00完走」を添える。
- 公開名にはAPIの `display_name` だけを使う。ChatGPTアカウント名、メールアドレス、クライアントの未確定距離は掲載しない。
- 選択中の難易度に対応するrulesetだけを取得する。男女は共通、旧rulesetは混在させない。難易度切替中の古い応答は破棄する。
- 読み込み中、0件、取得失敗は別の文言にする。1～2件の場合は実在する行だけを表示し、架空の記録を補わない。「更新」で再取得できる。
- 「ランク戦」の利用者向け表記を「ランキングに挑戦／参加」へ揃える。

## 受入

1. 選択画面ではゲームプレビューとHUDを表示せず、ランキング上位3人を表の同じ行に名前と距離を並べて表示する。
2. 開始操作でゲーム画面を表示し、入力・結果・再挑戦の流れを維持する。
3. 初級／中級／上級の切替、0～2件、4件以上、通信失敗、遅延した応答、スマートフォン幅を確認する。
4. Core、ruleset、D1、server側の順位・登録条件は変更しない。
